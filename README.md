# Local MP3 Player v9

GitHub Pages にそのまま配置できる、端末内MP3向けのPWAプレイヤーです。v7 の画面構成・キャッシュ式ライブラリ・遅延読み込み・暖色ナイトテーマを維持し、自動音響補正を追加しています。

## v9 の主な変更

- Gain範囲を `0.1× ～ 1.8×` に拡張
- 右上メニューに自動Gainモードを追加：補正なし / 平均RMS / 最大Peak
- RMS目標値・Peak目標値をメニューから設定可能
- P10～P90の音量分布を使う自動コンプレッサーを追加
- P10～P90の目標幅をメニューから設定可能
- 解析結果は裏で固定適用せず、既存のGain / threshold / ratio / knee / attack / release / makeupスライダーを約1.5秒かけて実際に動かして反映
- 自動反映後も各スライダーは通常どおり手動変更可能
- 解析結果を曲ごとに端末内キャッシュし、同じファイルの次回再生では再解析を省略
- 通常サイズの音源は全体をデコードして統計解析。長尺・巨大ファイルは再生中の短時間サンプル解析へ自動切替し、メモリ負荷を抑制
- v7以前の曲別Gain/コンプレッサー/ループ設定を読み込む後方互換を維持

## 自動解析について

全体解析時も統計計算はサンプル数に上限を設けて間引きます。無音に近い窓はP10～P90算定から除外します。長尺ファイルでは約9秒の再生サンプルから近似統計を作ります。そのためPeakや分位点は音響測定器としての厳密値ではなく、再生時の自動調整用の実用的な推定値です。

## GitHub Pages

このフォルダの中身を Pages の公開ルートへ配置してください。Service Worker のキャッシュ名は v9 に更新済みです。

## ローカルMP3と通信

MP3を外部へアップロードする処理はありません。自動音響解析もブラウザ内で行います。外部API/CDN/アクセス解析は使用せず、CSP は `connect-src 'none'` のままです。GitHub Pages からPWA本体を取得・更新確認する通常のWeb通信は発生します。


## v9 自動コンプレッサー
- ほぼ無音（約 -60 dBFS 以下）の時間窓を分位点統計から除外します。
- P30をしきい値にし、P30–P90が指定目標幅になるようRatioを推定します。
- P50が圧縮前と同じdBになるようMakeup Gainを逆算します。
- 上部の現在位置は「📁：ルート › 子フォルダ」で表示し、タップで親フォルダへ戻れます。
