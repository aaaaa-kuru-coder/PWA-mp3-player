# Local MP3 Player v4

GitHub Pages で配信できる、端末内 MP3 用のローカル PWA プレイヤーです。

## v4 の主な変更
- 通常起動時は IndexedDB のライブラリキャッシュを即表示し、音楽フォルダを毎回再走査しません。
- `☰` メニューから「ライブラリを更新」を実行したときだけフォルダ構造を再走査します。
- 更新時はまず MP3 のパスと FileSystemFileHandle だけを取得して一覧を更新します。
- ID3 の曲名・アーティスト・アルバムは未解析曲だけ後から少しずつ取得し、結果を IndexedDB に保存します。
- APIC（埋め込みジャケット）は原則として再生した曲だけ読み込みます。
- ループ設定はプレイヤーの `…` メニューへ移動し、既定は「1曲ループ」です。
- 「1曲ループ」「現在の一覧を繰り返す」「ループなし」を選べます。
- Gain・コンプレッサー・ループモードは曲別に localStorage へ保存します。
- v3 / v2 の既存設定も可能な範囲で読み取ります。

## 初回利用
1. 右上の `☰` →「音楽フォルダを登録・変更」
2. 音楽フォルダを選択
3. フォルダ構造だけを先に読み、一覧を表示
4. 未解析の ID3 文字情報はバックグラウンドで取得
5. ジャケットは曲を再生したときに取得

## 2回目以降
前回保存したライブラリキャッシュを先に表示します。新しく曲を追加・削除した場合だけ、`☰` →「ライブラリを更新」を実行してください。

## プライバシー
MP3 本体を外部へアップロードするコードはありません。`connect-src 'none'` を設定し、外部 API / CDN / Analytics / 広告も使用していません。PWA 本体の更新確認など GitHub Pages との通常の Web 通信は発生しますが、ローカル MP3 をその通信へ載せる処理はありません。
