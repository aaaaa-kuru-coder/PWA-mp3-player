# Local MP3 Player v7

GitHub Pages にそのまま配置できる、端末内MP3向けのPWAプレイヤーです。

## v7 の主な変更

- 画面を「上部操作 / 曲一覧 / 再生操作」の3領域に固定し、通常画面で縦スクロールするのは曲一覧だけに変更
- 下部プレイヤーは通常約8%のミニ表示、展開時は上部操作欄の直下まで広がるボトムシート方式
- ミニプレイヤーは再生ボタン以外をタップ、または上スワイプで展開
- 曲一覧の標準行高をv6比で約1.5倍へ拡大
- 右上メニューから曲一覧サイズを「小さめ / 標準 / 大きめ」に変更可能（端末内に保存）
- タイトルを `Local MP3 Player` に簡素化
- 青基調から暗い赤茶・オレンジ基調のナイトテーマへ変更
- v6までのキャッシュ式ライブラリ、遅延ID3、遅延ジャケット、手動差分更新、曲別Gain、コンプレッサー、ループ設定を維持
- v6以前の曲別設定を読み込む後方互換を維持

## GitHub Pages

このフォルダの中身を Pages の公開ルートへ配置してください。Service Worker のキャッシュ名は v7 に更新済みです。

## ローカルMP3と通信

MP3を外部へアップロードする処理はありません。外部API/CDN/アクセス解析も使用せず、CSP は `connect-src 'none'` のままです。GitHub Pages からPWA本体を取得・更新確認する通常のWeb通信は発生します。
