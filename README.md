# Local MP3 Player v5

GitHub Pages で配信できる、端末内 MP3 用のローカル PWA プレイヤーです。v4 のキャッシュ式ライブラリ・遅延 ID3・遅延ジャケット・手動更新方式を維持しつつ、スマホ向け UI を整理しました。

## v5 の主な変更
- 再生パネルを画面下部のドロワー式に変更しました。
- 収納時はアルバム画像・タイトル・再生/停止ボタンだけを表示します。
- 取っ手のタップ、上スワイプ/下スワイプで展開・収納できます。
- Gain、シーク、前後移動、ループ設定、コンプレッサーは展開時だけ表示します。
- アプリ仕様・プライバシー説明は通常画面から外し、右上 `☰` メニュー内へ移しました。
- 表示モードを `🎵 全曲 / 📁 フォルダ / 👤 アーティスト / 💿 アルバム` の4ボタン1段固定にしました。
- ヘッダーの `MP3 Player` を小型化しました。
- キャッシュ一覧から曲を選択した際にフォルダ権限が切れている場合、曲の位置で許可モーダルを表示し、許可後は選んだ曲の読み込み/再生を自動再開します。

## 高速起動
- 通常起動時は IndexedDB のライブラリキャッシュを表示し、音楽フォルダを毎回再走査しません。
- `☰` →「ライブラリを更新」を実行したときだけフォルダ構造を再走査します。
- ID3 の文字情報は未解析曲だけ後から取得します。
- 埋め込みジャケット画像は原則として再生した曲だけ読み込みます。

## プライバシー
MP3 本体を外部へアップロードするコードはありません。`connect-src 'none'` を設定し、外部 API / CDN / Analytics / 広告も使用していません。PWA 本体の取得・更新確認など GitHub Pages との通常の Web 通信は発生しますが、ローカル MP3 をその通信へ載せる処理はありません。
